# Website Accessibility

A comprehensive WordPress accessibility plugin that meets WCAG 2.0 (AAA) standards with features like flexible settings, multilingual voice navigation, color modes, and more.

## Description

Website Accessibility is a powerful accessibility solution for WordPress that helps make your website accessible to users with various disabilities and impairments. The plugin provides a wide range of accessibility features and is fully compliant with WCAG 2.0 (AAA) standards.

### Key Features

- Flexible accessible settings set
- Draggable accessibility window
- Appearance animation of the accessibility button
- Multilingual Voice Navigation
- Flexible style settings of the button
- Code meets standards WCAG 2.0 (AAA)
- Text recognition powered by Google Cloud API
- Day(Light) and Night(Dark) Color Modes
- Automatically languages recognizing across 40+ languages
- Compatible with Elementor, WPBakery Page Builder, and Visual Composer
- Works well with all popular WordPress Themes
- 7 Positions for placing the accessibility button
- Perfect for RTL direction
- Native valid JavaScript, without jQuery
- Huge customization capabilities
- Beautiful modern user Interface
- Compatible with WordPress 6+
- Lightweight and Fast
- Compatible with all modern browsers

### Accessibility Features

- **Reading Experience**: Text magnifier, font size controls, line height adjustment, letter spacing, dyslexia-friendly font, and more.
- **Visual Experience**: Dark mode, high contrast mode, color adjustments, monochrome mode, and more.
- **Navigation Aids**: Reading guide, reading mask, highlight focus, big cursor, keyboard navigation, etc.
- **Input Methods**: Voice navigation, text-to-speech, virtual keyboard, etc.
- **Cognitive Aids**: Highlight titles and links, cognitive reading, online dictionary, etc.

## Installation

1. Upload the `website-accessibility` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to 'Accessibility' in your admin menu to configure the plugin

## Frequently Asked Questions

### Is this plugin compatible with my theme?

Yes, Website Accessibility is designed to be compatible with all standard WordPress themes and popular page builders.

### Does this plugin slow down my website?

No, Website Accessibility is built to be lightweight and only loads the necessary resources. The main accessibility features are loaded only when a user activates them.

### Can I customize the accessibility button?

Yes, you can customize the button's position, size, color, icon, and animation type from the plugin settings.

### Does this plugin comply with accessibility standards?

Yes, Website Accessibility is built to comply with WCAG 2.0 (AAA) standards.
